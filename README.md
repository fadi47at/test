# Fadi's Design Library

A small collection of interactive web design work, deployed on GitHub Pages.

## What's here

- **VAD** (`/vad/`) — An AI coding assistant landing page, inspired by MiMo Code. Cream + serif + an ink-reveal canvas effect.
- **Gallery** (`/gallery/`) — 20 distinct website design directions, each with 3 creative variations. Click any design to browse it live.
- **Quanta** (`/gallery/quanta.html`) — A complete online learning platform design (inside the gallery folder).
- **Landing** (`/`) — The library index.

## Tech

Pure HTML + CSS + JavaScript. No build step, no dependencies. Drop it on any static host (GitHub Pages, Netlify, Vercel, S3, etc.).

## Local development

```bash
python -m http.server 8080
# Then open http://localhost:8080
```
